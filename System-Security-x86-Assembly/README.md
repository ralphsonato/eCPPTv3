# System Security & x86 Assembly Fundamentals - Anotações de Estudo (eCPPT)


## Sobre este curso

Este é o módulo de **System Security**, o objetivo é construir a base de conhecimento sobre arquitetura de computadores, linguagem assembly e mecanismos de segurança que dá suporte a tópicos avançados como fuzzing, exploit development, buffer overflows, debugging, engenharia reversa e análise de malware (explorados em profundidade no curso de Exploit Development).

Assembly é a porta de entrada para entender técnicas de exploração, engenharia reversa e shellcoding. Sem um bom domínio de arquitetura de sistemas e assembly, não é possível dominar essas áreas de forma efetiva.



## Pré-requisitos

- Entendimento básico de conceitos de arquitetura de computadores
- Familiaridade com linguagens de baixo nível como C ou C++
- Proficiência em Linux (navegação por linha de comando e manipulação de arquivos)
- Algum conhecimento de assembly é benéfico, mas não obrigatório

---

## Objetivos de Aprendizado

1. **Fundamentos de Arquitetura de Computadores** - princípios de arquitetura de CPU e memória de processo; papel da CPU, registradores e memória
2. **Arquitetura IA-32** - registradores, instruction set, pipeline de execução; função dos general-purpose registers
3. **Organização de Memória** - regiões de memória (code, data, heap, stack) e seus papéis na execução
4. **Stack e Stack Frames** - a estrutura de dados stack e seu papel em chamadas de função e variáveis locais
5. **Introdução ao Assembly IA-32** - definição e papel do assembly; diferenças entre linguagens de alto nível e assembly
6. **Básico de Assembly IA-32** - instruções aritméticas/lógicas, movimentação de dados e modos de endereçamento de memória

## Onde este conhecimento é aplicado

Este curso é a **fundação** para o curso de Exploit Development, onde os conceitos aprendidos aqui são aplicados em:
- Buffer Overflows
- Fuzzing
- Shellcoding
- Engenharia reversa
