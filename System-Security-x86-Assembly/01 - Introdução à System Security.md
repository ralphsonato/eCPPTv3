# Introdução à System Security



## O que é este curso

System Security é o curso projetado para dar a pentesters e red teamers o conhecimento fundamental de **arquitetura de computadores, linguagem assembly e mecanismos de segurança**.

O propósito é fornecer a base necessária para melhorar habilidades em tópicos como:

- Fuzzing
- Exploit development
- Buffer overflows
- Debugging
- Engenharia reversa (reverse engineering)
- Análise de malware

> Esses tópicos são explorados em profundidade no **curso de Exploit Development**. Este curso é a fundação que torna aquele possível.


## O que vou aprender

- Arquitetura de CPU
- Gerenciamento de memória (memory management)
- Detalhes dos instruction sets x86 e x64
- Básico da linguagem assembly de 32 bits para a família de processadores Intel (IA-32) no Linux
- Como aplicar assembly à segurança da informação (Infosec)



## Por que assembly importa

Assembly é a **porta de entrada** para entender:

- Técnicas de exploração (exploitation)
- Engenharia reversa
- Shellcoding
- Outros campos de baixo nível da segurança da informação

**Sem um bom domínio de arquitetura de sistemas e assembly, não é possível dominar essas áreas de forma efetiva.** É por isso que este curso vem antes do Exploit Development na trilha de aprendizado.



## Progressão da trilha
